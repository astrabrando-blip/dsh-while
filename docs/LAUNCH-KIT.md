## Release 正文
while 是一个 DSH 全局助理插件，把持续对话、目标、点子和多个任务的协作放在一起。

这次预览版包含：目标管理；从历史任务和目标中发现下一步；点子反馈与删除；按请求读取、新建和继续 Session；活动与文件产物列表；深浅主题适配。

安装前请查看 README 的版本与权限说明。附件提供预构建 tgz 与 SHA256 校验值。开发环境验证版本为 DSH Desktop 0.2.0-rc.2 / macOS，独立发布包验证见 docs/VALIDATION.md。

## 社区发布文案
我做了一个 DeepSeek Harness 插件，叫 while。

希望它不只是回答当前这一句，也能把之前聊过的事接起来：记住长期目标，看看手头任务还可以怎么推进，需要时协作管理多个 Session。

我最想打磨的是“点子”：根据真实需求，推荐一件你看了觉得“哦，可以这样”的事。可以是把研究落地，也可以是补一个真正有用的插件能力。

目前是开发者预览版，欢迎拿真实任务试用，反馈哪些建议有用、哪些理解偏了。

发布时附上真实仓库和 Release 链接，不使用占位链接直接发布。

## 约 60 秒视频脚本
- 0–8 秒：展示空白演示环境，标题“让聊过的事，成为下一步”。
- 8–20 秒：输入“我想持续关注 Agent 自进化”，打开目标页看到简短目标。
- 20–35 秒：补充一个真实工作场景，点击发现并发送。剪辑等候段，明确字幕“生成过程已加速”。
- 35–48 秒：展示真实生成的点子，点开查看内容，引用到聊天并发起下一步。
- 48–58 秒：打开鲸鱼活动入口，展示真实 Session 与实际文件产物。
- 58–60 秒：展示 while、仓库地址、开发者预览版。

录屏使用独立演示环境；不要录制现有私人会话、真实账号或未核实研究结果。封面 SVG 是品牌素材，不是假装已发生的产品截图。
