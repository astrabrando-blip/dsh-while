# 发布验证记录

日期：2026-10-15；版本：0.1.0-preview.1。

## 已完成

- 独立目录通过 npm 注册表安装声明依赖，未复用开发环境 node_modules 符号链接，安装时禁用生命周期脚本。
- 44 个运行文件的入口、manifest、JS 语法、本机路径和私钥标记检查通过。
- 15 项测试通过：点子来源、字段纠错、反馈持久化、删除、插件目录、Session 调度和结果投递。
- npm pack 生成预构建 tgz，仅包括白名单内容。
- 使用官方 DSH Desktop 0.2.0-rc.2 随附 CLI，在全新 DSH_HOME、由 web 模板创建的 profile 中安装 tgz 成功。
- 独立 Web 实例启动成功；浏览器实测 while 入口、空白主聊天、点子页和“发现”进入可编辑主聊天草稿。
- 安装器有 peer 提示；运行时前后端加载和初始身份读取成功，不代表所有宿主版本都满足约束。
- 真实首次安装截图见 ../media/first-install.png，无账号或私人任务。

## 未验证

全新环境未配置模型凭据，未发送模型请求，因此本包尚未在全新环境重新验收模型生成、子 Session 执行和结果回流。未验证其他 DSH 版本、Windows/Linux Desktop、GitHub 远程安装和 npm 发布。语义生成质量仍需实际任务校准。此包应作为开发者预览，不能宣传为全面验收的稳定版。

Release 已发布为预览版，仓库保持私有；封面是品牌图，不是运行截图。

2026-10-15 从 Release 下载 `.tgz`，SHA256 与发布资产一致。在全新 DSH_HOME 的 web profile 中执行发布页安装命令成功，启动独立实例后，while 侧栏入口、聊天、点子和目标页正常初始化。首次启动跳过模型密钥配置，因此未验证模型回复或生成任务。安装有 peer dependency 警告，但未阻止此版本启动。
