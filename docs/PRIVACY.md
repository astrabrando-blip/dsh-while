# 数据与权限

- 存储归属：DSH 所选数据环境中的插件存储与 Session。目标、点子、反馈、记忆和任务关系会持久保存。
- 全局上下文：按用户请求查询工作区与普通任务，并读取相关会话；历史文本不构成新的执行授权。
- 模型：使用宿主配置的服务与凭据。被选作上下文的消息、目标和工作内容会进入模型请求。不是“所有内容永不出本机”的产品。
- 网络：公开插件目录来源为 GitHub；相关研究工具按宿主配置与权限工作。没有独立的 while 分析埋点服务。
- 写入与执行：确认目标只保存关注项；点子不会因浏览而执行。发送后由既有任务调度和宿主权限处理。
- 删除：点子删除是持久软删除，隐藏于列表；不承诺擦除原始聊天、日志、备份或模型服务记录。记忆“忘记”停止召回，不等于抹除源消息。
- 卸载：停用或卸载插件不自动清除历史。需要彻底清理时先备份，并通过宿主的数据管理处理对应环境。
- 发布包：不包含开发者聊天记录、账号、API key、测试环境和截图。
